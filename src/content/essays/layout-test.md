Footnotes are written in ordinary Markdown.[^1] On a wide screen they appear in the right margin next to the line that references them; on a phone, tap the number to expand the note in place. Citations work the same way.[^2]

## Writing an essay

Create a Markdown file in `src/content/essays/`. The file name becomes the address, so `causal-models.md` is published at `/essays/causal-models/`. Every `##` and `###` heading appears in the table of contents on the left, which follows you as you scroll.

Long essays benefit from a clear structure. Each section should make one point, and the headings should read like a summary of the argument when scanned on their own.[^3]

### A subsection

Subsections are indented in the table of contents. Use them sparingly.
